# Appart Beni Mellal - Thème Clair 🏠

Site vitrine moderne pour location d'appartements à Béni Mellal. Version Light, responsive et optimisée pour les entreprises locales.

🔗 **Live Demo:** https://atlas-web-ma.github.io/appart-beni-mellal-light/

## ✨ Features
- Design clair et épuré pour location immobilière
- 100% Responsive (Mobile, Tablette, PC)
- Galerie photos des appartements
- Section contact et réservation
- Animations CSS modernes

## 🛠️ Technologies
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript Vanilla
- GitHub Pages

## 🎯 Objectif
Création d'un modèle réutilisable pour les agences immobilières locales à Béni Mellal et région.
